# Shikaky

Дві гри в одному застосунку: логічна головоломка **Shikaku** і аркада на злиття **Жабки**.

## Shikaku

Головоломка **Shikaku** (四角に切れ — «розріж на прямокутники») у неo-брутальному аркадному стилі.
Розріж поле на прямокутники так, щоб у кожному було рівно одне число, а площа прямокутника
дорівнювала цьому числу. Поле має бути закрите повністю, без перетинів і без дірок.

## Запуск

```bash
npm install
npm run dev      # локальний сервер Vite
npm run build    # типова перевірка + збірка у dist/
npm run preview  # перегляд зібраної версії
npm test         # генератор, солвер і всі 320 рівнів
```

Shikaku не має рантайм-залежностей узагалі: анімації на CSS, звук на WebAudio,
конфеті на Canvas. Жабки використовують PixiJS, Matter.js і GSAP.

## Що всередині

```
src/core/     чиста логіка, нічого не знає про DOM
  rng.ts        детермінований PRNG (mulberry32) + хеш сіда
  solver.ts     backtracking з MRV і відсіканням недосяжних клітинок
  generator.ts  нарізка поля на прямокутники + перевірка унікальності розвʼязку
  levels.ts     каталог блоків, рівень → сід → головоломка, щоденна гра
  game.ts       стан партії Shikaku: фігури, undo/redo, підказки, перевірка перемоги
  pond.ts       гра Жабки на Matter.js: ланцюжок, злиття, комбо, струс
  storage.ts    прогрес і налаштування у localStorage
src/ui/       рендер і ввід
  board.ts      дошка Shikaku: три шари (клітинки, фігури, числа), драг, клавіатура
  pond.ts       рендер Жабок на PixiJS: текстури, мордочки, ефекти
  frogArt.ts    малювання жабок у canvas → текстури Pixi
  screens.ts    меню, вибір рівня, гра, фініш
  fx.ts         конфеті, тряска, вібрація, тости
  sound.ts      синтезовані звуки без жодного аудіофайлу
src/styles/   токени, дошка, екрани
```

### Рівні

Рівні не зберігаються у файлах — вони **виводяться з номера рівня**:

```
рівень → hashSeed("shikaky-v1-<блок>-<номер>") → generatePuzzle() → та сама дошка в усіх
```

Генератор ріже поле на прямокутники, кидає в кожен число у випадкову клітинку і віддає
результат солверу. Дошка приймається, лише якщо розвʼязок **рівно один**. Додатково
перевіряється «смуга складності» — скільки разів солвер мусив вгадувати:

| Блок | Поле | Макс. площа | Здогадки | Рівнів |
|------|------|-------------|----------|--------|
| Розминка | 5×5 | 6 | 0 | 40 |
| Ритм | 7×7 | 8 | 0–1 | 50 |
| Тиск | 9×9 | 9 | 1–4 | 50 |
| Вузол | 10×10 | 12 | 2–8 | 50 |
| Хаос | 12×12 | 14 | 3–24 | 50 |
| Лабіринт | 13×13 | 16 | 4–30 | 40 |
| Безодня | 15×15 | 18 | 6–50 | 40 |

Разом 320 рівнів; усі 320 генеруються приблизно за секунду (тест `npm test` це перевіряє).

Прогрес зберігається під ключем виду `t5.30` — блок і номер усередині блоку. Тому блок можна
розширити, не зсуваючи чужу історію; збереження старого формату (глобальні номери) переноситься
автоматично при першому запуску.
Щоденна гра бере сід із дати, тож в усіх однакова.

Щоб додати блок — додай запис у `TIERS` (`src/core/levels.ts`). Номери рівнів і сіди
порахуються самі. Зміна алгоритму генерації змінює всі дошки, тому сід має префікс версії.

## Жабки — друга гра

Аркада жанру drop-and-merge (той самий рід, що Suika Game): кидаєш жабку у ставок,
дві однакові зливаються в наступну за розміром. Ланцюжок із 12 ступенів —
ікринка → пуголовок → жабеня → квакша → ропуха → блакитна → отруйна → рожева →
фіолетова → червона → царівна → **Цар-Жаб**. Очки рахуються в мухах.

Стек саме цієї гри:

| Що | Чим |
|----|-----|
| Фізика | **Matter.js** — кола, сон тіл, реалістичні контакти |
| Рендер | **PixiJS 8** (WebGL) — жабки як текстури, намальовані один раз |
| Анімація | **GSAP** — приліт, приплюснення, кільця злиття, моргання |

Фішки жанру: черга з двох наступних жабок, **комбо-множник** (злиття поспіль
коштують у 2-8 разів дорожче), **струс ставка** (три на спробу), колекція-ланцюжок
унизу, рекорд.

Ставок — це шар за шаром: градієнт глибини, розфокусовані водорості, промені
сонця (шейдер `GodrayFilter`), боке-порошинки, що піднімаються з дна, світлячки,
брижі на поверхні, розмите латаття на передньому плані й скляний відблиск зверху.
Місце, де росте стос, спеціально підсвічене — дія має бути найяскравішим на екрані.
Жабки мають контровий блік по тіньовому краю, інакше їхній чорний контур тоне у воді.

Жабки живі: очі з білком і зіницями **стежать за тим, що падає** — коли щось
летить згори, увесь ставок дивиться вгору. Моргають, а ще мають настрої: переляк
під падаючою жабкою, замружені очі від удару, щастя після злиття, ××-очі від
струсу, тривога біля червоної лінії.

Два правила у `src/core/pond.ts` неочевидні, і кожне стоїть на тесті:

- жабка, що народилась зі злиття, не зливається далі в тому ж кроці — інакше стос
  розсмоктується сам і ставок неможливо переповнити;
- програш зараховується, навіть якщо стос рухається: інакше гравець, який швидко
  кидає, безсмертний.

Matter інтегрує через `delta²`, тому крок симуляції **фіксований** (1/60). Із
довільним кроком від кадру гравітація «пливе» — жабки буквально зависають угорі.

Довжина партії підбиралась заміром: випадкова гра закінчується за 96-155 кидків.

## Керування

- **Мишею / пальцем**: протягни — намалюєш прямокутник. Тап по фігурі прибирає її.
- **З клавіатури**: Tab до поля, стрілки — курсор, Enter — почати й завершити прямокутник,
  Escape — скасувати, Backspace — прибрати фігуру під курсором.
- Смугаста червона фігура означає, що в ній не одне число або площа не збігається.

## Стиль

Неo-брутал: 3px чорна обводка, жорсткі зміщені тіні без блюру, насичені кольори,
фігура «гепається» на поле з відскоком. Заливки — світлі тінти палітри, щоб чорне число
читалося завжди; **колір фігури залежить від числа**, тож однакові числа виглядають однаково.
Є нічна тема (авто / день / ніч) і вимикач ефектів; `prefers-reduced-motion` вимикає рух сам.

## Прогрес і його відновлення

Прогрес лежить у localStorage цього браузера (`shikaky.v1`). Кнопка 💾 у верхньому рядку
(або «Відновити прогрес» у меню) відкриває аркуш «Прогрес» із двома способами повернути рівні:

1. **Відновити рівні.** Вкажи останній пройдений рівень — усі рівні до нього стануть
   пройденими. Часу в рекордах у них немає, тому в клітинці буде «—», а перше справжнє
   проходження такого рівня одразу стає рекордом.
2. **Код перенесення.** Один рядок тексту з усім збереженням: відкрий стару адресу гри,
   скопіюй там код і встав його тут.

Збереження ніколи не затирають одне одного — вони **зливаються** (`mergeSaves` у
`src/core/storage.ts`): для спільного рівня лишається кращий час, для щоденної — менший,
для Жабок — більший рахунок. Відновлений рівень без часу завжди програє справжньому
проходженню.

## PWA

`public/sw.js` кешує гру cache-first, але саму сторінку тягне з мережі, коли вона є —
інакше встановлена на телефон копія показувала б стару збірку вічно.
`manifest.webmanifest` дає встановлення на телефон.
